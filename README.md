# Makomborero Busu — Portfolio

A responsive, animated, static portfolio website built with HTML, CSS and vanilla JavaScript. No build tools, package installation or backend required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create or open a GitHub repository (for example, `Portfolio-Makomborero`).
2. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css` and `script.js` together.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will publish the site and show its public URL in the Pages section.

You can also drag the folder into Netlify Drop or deploy the repository through Netlify.

## Personalise before publishing
- Check every project description and role title for accuracy.
- Replace the email address if you want a different public contact address.
- Add your LinkedIn URL and any public project/demo links when ready.
- Add a headshot or project screenshots if you want them; the current design intentionally uses CSS artwork and does not depend on image assets.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, responsive styling and animations
- `script.js` — mobile navigation, current year and scroll reveals
